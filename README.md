# Лабораторная работа №2 - GitHub

1.Прослушать курс (3 урока) <a href="https://www.youtube.com/playlist?list=PL3LQJkGQtzc5rDeb7FjACNb6sOW300yA0">"GitHub для новичков"</a>

2.Посмотреть видео <a href="https://vkvideo.ru/video-182420474_456239398">"Git и GitHub Курс Для Новичков"</a>

3.Почитать теоретический материал:

&emsp;• Подробно: <a href="https://skillbox.ru/media/code/chto-takoe-github-i-kak-im-polzovatsya/">Skillbox</a>

&emsp;• Кратко: <a href="https://habr.com/ru/articles/541258/">Habr</a>

4.Потренироваться для закрепления теории: Пройти первые 4 урока на сайте: <a href="https://learngitbranching.js.org">Learn Git Branching</a>

5.Зарегистрироваться на GitHub.

6.Создать git-репозиторий.

7.Загрузить проекты заданий лаб. работ.

8.Добавить к репозиторию файл README.md в формате Markdown со следующей информацией:

&emsp;• исполнитель;

&emsp;• название и формулирование задания;

&emsp;• описание того, в какой среде программирования можно открыть проект, какой файл проекта следует открывать;

&emsp;• как запускать вашу программу, и как ей пользоваться;

&emsp;• скриншоты тестов.

<a href="https://github.com/GnuriaN/format-README">Ссылка</a> на справочник по синтаксису README.md

9.В качестве решения отправьте ссылку на git-репозиторий.
